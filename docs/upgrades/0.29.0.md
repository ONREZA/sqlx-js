# Upgrade to 0.29.0

This guide applies to applications upgrading from `0.28.x`. Version 0.29.0
adds exact reusable-query assertions for array-element nullability and changes
the committed query cache and declaration-generator revisions.

## Regenerate live artifacts

The query cache is now format 7 and the declaration generator is revision 24.
Old artifacts fail closed with regeneration guidance. Run against the
canonical development or shadow schema:

```bash
sqlx-js prepare
sqlx-js prepare --check --strict-inference
tsc --noEmit
```

Commit `.sqlx-js/` and `sqlx-js-env.d.ts` together.

`queries --json` inventory entries now include aggregated `resultAssertions`,
and `queries explain --json` includes the exact assertions for each profile
contract. These are additive `formatVersion: 1` fields.

## Replace result adapters only where the invariant is owned

PostgreSQL array value nullability and element nullability are independent.
When an opaque expression or function `OUT` field is known by the application
to contain no SQL `NULL` elements, declare that exact query contract:

```ts
export const claimDelivery = defineQuery.one(
  "delivery.claim",
  `SELECT capabilities AS "capabilities!" FROM claim_delivery()`,
  { resultAssertions: { capabilities: { elements: "non-null" } } },
);
```

Live prepare verifies that `capabilities` is an output column with a PostgreSQL
array type and generates `T[]` instead of `(T | null)[]`. It does not execute
the query or inspect function bodies, so this remains an application-owned
semantic assertion. Keep runtime validation when the application does not own
that invariant.

Use a PostgreSQL `DOMAIN ... NOT NULL` element type when the database owns the
invariant, or `arrayElementNullability` when it belongs to a direct stored
column. `resultAssertions` is intentionally scoped to a literal `defineQuery`
instead of naming a function or globally narrowing a column name.

## Rollback

Restore version 0.28.x and its matching generated artifacts together. Do not
ask the older CLI to read or rewrite format-7 query caches.
